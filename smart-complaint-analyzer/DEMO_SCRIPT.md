# Live Demonstration — 5 to 7 minutes
**0:00–0:45** Explain civic complaint reporting and why manual categorization is slow. State this is an academic prototype, not a government portal.

**0:45–1:30** Register a citizen or sign in with the demo account. Show dashboard and New Complaint.

**1:30–2:30** Submit: `Large pothole near the school` / `The road outside the school has several large potholes.` / `School Road` / `Demo City`. Show predicted category, model confidence estimate, assigned department, and rule-based priority explanation.

**2:30–3:15** Submit a similar second report and show similarity percentages and disclaimer. Show citizen status timeline.

**3:15–4:45** Log out, sign in with administrator credentials created via CLI. Show admin dashboard, filter complaints, open the new complaint, assign department, change status to `Under Review`, and add a review note.

**4:45–5:30** Log out and return as the citizen. Show the updated status and timestamped history.

**5:30–6:30** Return as admin; show live charts, frequent locations and CSV export. Mention offline ML, synthetic-data limitations, and future multilingual support.
